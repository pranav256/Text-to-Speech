# Text-to-Speech Synthesizer

A voice synthesis desktop utility utilizing the Google Text-to-Speech (`gTTS`) engine and Python audio playback.

## Features

- **Audio Synthesis:** Converts plain text input into spoken MP3 audio files.
- **Instant Playback:** Plays generated speech immediately using the `playsound` library.
- **Language Options:** Supports accent and language selection parameters.

## Tech Stack

- Python 3.8+
- gTTS (`gTTS`)
- Playsound (`playsound`)

## Run

```bash
pip install gTTS playsound
python main.py
```
